For training purposes. </br>
</br>
Remake: https://design-3-locomotive.vercel.app/ </br>
Original website: https://locomotive.ca/

## Tech stack

- React 19
- GSAP 3
- Lenis scroll
- Vite 7

## Setup

Install:

```js
npm i
```

Run:

```js
npm run dev
```
